# Feature 1: Member Profile Management

Track and update church member profiles in one place.

## Goals

- Create, view, edit, and archive member profiles
- Store contact details, household, and membership status
- Keep profile history so staff can see what changed

## Profile fields

- Full name
- Preferred name
- Phone, email, and address
- Date of birth
- Household / family
- Membership status (visitor, member, inactive)
- Notes

## Out of scope

- Attendance tracking
- Giving / donations
- Event registration
